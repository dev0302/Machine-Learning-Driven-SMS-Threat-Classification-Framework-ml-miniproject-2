# ScamLens ML

This folder contains the training notebook, dataset location, saved model location, and the small FastAPI inference backend. The Next.js frontend is maintained separately.

## Structure

- `main.ipynb` — existing notebook for data analysis, training, evaluation, and model export.
- `data/LSDST-2022.csv` — put the dataset here.
- `models/scamlens_model.pkl` — generated by the notebook's final cell.
- `backend/main.py` — FastAPI endpoints.
- `backend/features.py` — shared text preprocessing plus extra message indicators.

## 1. Place the dataset

Copy `LSDST-2022.csv` into `ml/data/`.

## 2. Run the notebook

Open `ml/main.ipynb` with the notebook working directory set to `ml/` (or the project root). Run the notebook in order. The notebook has been updated to read from `data/LSDST-2022.csv` and save the final Logistic Regression pipeline to `models/scamlens_model.pkl`.

The backend does not train a model; it only loads the exported artifact.

## 3. Install and start the API

From `ml/backend/`:

```bash
python -m pip install -r requirements.txt
python -m nltk.downloader stopwords punkt punkt_tab
uvicorn main:app --reload
```
Step 1: Install Uvicorn and FastAPI
Run this in your backend terminal:

python -m pip install fastapi uvicorn


Step 2: Start your FastAPI server

python -m uvicorn main:app --reload


The API runs at `http://127.0.0.1:8000`. Interactive documentation is at `http://127.0.0.1:8000/docs`.

## Endpoints

- `GET /health`
- `POST /predict`

Example request body:

```json
{
  "text": "Congratulations! You have won a prize. Claim now."
}
```

The response includes `label` (`ham`, `smishing`, or `spam`), `class_id`, confidence/probabilities when supported, and a few message indicators. The numeric indicators are informational only; the current classifier uses the preprocessed text with TF-IDF.

## Next.js integration

Send a POST request to `http://127.0.0.1:8000/predict` with JSON `{ "text": "..." }`. When deployed, add the frontend origin to the CORS allowlist in `backend/main.py`.

## Notes

- The notebook uses `LabelEncoder`; its classes are `ham`, `smishing`, and `spam` in alphabetical order, mapped to IDs 0, 1, and 2.
- Pickle files can execute code when loaded. Only load model files produced by your own trusted notebook.
